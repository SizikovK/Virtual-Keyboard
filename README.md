# Virtual Keyboard

Обучение модели точек руки на GPU:

```bash
.venv/bin/python src/train.py --device 0
```

По умолчанию: до 150 эпох, batch 8, размер изображения 640, весь тренировочный
датасет. Ранняя остановка после 30 эпох без улучшения метрик валидации.
Без `--device 0` используется CPU.

Количество эпох и размер пакета можно изменить:

```bash
.venv/bin/python src/train.py --device 0 --epochs 100 --batch 16
```

Датасет задаётся в `configs/hand-keypoints.yaml`.
Некорректные метки исходного датасета Ultralytics пропускает при загрузке.
Для приложения используйте `weights/best.pt` из папки завершённого запуска,
путь к которой выводится в логе обучения.
