# Virtual Keyboard

Виртуальная клавиатура с управлением пальцами через веб-камеру.
Запускайте команды из корня проекта. Нужны Python, веб-камера и графический сеанс.

## Установка

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

## Запуск

Нужна обученная модель руки с 21 ключевой точкой. Укажите путь к её весам:

```bash
.venv/bin/python src/main.py --weights /путь/к/best.pt
```

Программа использует первую камеру (`source=0`). Наведите кончики пальцев
на кнопки A, W, D, S, SPACE и SHIFT. Можно удерживать несколько кнопок одновременно.
Для ввода переключитесь в нужное приложение или Minecraft.
Если GNOME попросит разрешить управление вводом, подтвердите запрос.
Для выхода нажмите `q` в окне камеры или `Ctrl+C` в терминале.

## Обучение своей модели

Датасет задаётся в `configs/hand-keypoints.yaml`.

```bash
.venv/bin/python src/train.py --device 0 --epochs 150 --batch 8
```

`--device 0` — NVIDIA GPU с поддержкой CUDA в PyTorch; `--device cpu` — CPU.
По умолчанию используются все тренировочные данные и размер изображения 640.
Путь к результатам выводится в логе. Для запуска возьмите `weights/best.pt`
из папки обучения, обычно `runs/pose/hand-tracking/train*/`.
